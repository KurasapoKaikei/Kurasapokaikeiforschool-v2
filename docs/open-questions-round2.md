## Q4. 振替（口座間のお金の移動）は必ず 2 行セットですか

「現金から普通預金へ 5 万円移した」という振替を登録すると、帳簿には次の 2 行が作られます。

| | 科目 | 金額 |
|---|---|---|
| 出ていく側 | 現金 | 50,000 |
| 入ってくる側 | 普通預金 | 50,000 |

**質問**: この 2 行は**必ずセット**として扱われますか。

- [〇] **必ずセット**。片方だけ消したり金額を変えたりはできない（＝必ず両方が同時に変わる）
- [ ] **片方だけ**の削除・修正もできてよい

**なぜ聞くか**: 片方だけ消せてしまうと、現金は減ったのに預金が増えていない、という帳簿の不整合が起きます。「必ずセット」ならシステム側で強制的に守るようにします。

## 前回の回答で確定したこと（確認のみ・回答不要）

| 内容 | 決まったこと |
|---|---|
| 会計期間 | 学校ごとに違ってよい。**申込時に入力する決算日**から計算する（例: 8/20 決算なら 8/21〜8/20） |
| 年度の切り替え | 繰越をすると次年度が作られる。過去 **7 年分**を見られるようにする |
| 実際に使っている学校 | **0 校**。データの引っ越し作業はほぼ不要になった |
| 金額 | **円単位の整数**。マイナス（返金・取消の △ 表示）あり。小数は使わない |
| 部分入金・過入金 | **あり**。1 つの集金予定に対して、複数回に分けた入金を記録できるようにする |
| Excel の CSV | 文字化けを自動で直す仕組みを入れる。加えてテンプレートを Excel 形式で配る |
| 顧問と監査人 | **顧問＝クラブ責任者**。監査人は学校側の立場で別。監査人を通すかは申込時に選ぶ |
| 保護者 | まずは閲覧のみ。将来はクラブ ID ＋ 部員パスワード（年度ごとに再発行） |
| 保存期間 | **7 年**。部員の個人情報も同じ |
| 学校共通のカテゴリー・科目 | クラブ側では編集できない |
